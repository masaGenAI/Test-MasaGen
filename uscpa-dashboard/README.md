# USCPA 学習ダッシュボード

USCPA（アビタス）5科目の学習を一元管理する統合ダッシュボードです。
**FAR1-3 / FAR4-5 / AUD / REG1 / REG2** の進捗・試験日・演習成績・カリキュラムを1画面で俯瞰できます。

## 使い方

`uscpa-dashboard/index.html` をブラウザで開くだけです。
サーバ・インストール・依存関係は不要（自己完結型の単一HTML）。

```
# ローカルで開く例
open uscpa-dashboard/index.html        # macOS
xdg-open uscpa-dashboard/index.html    # Linux
```

## 4つの機能

| タブ | 内容 |
|------|------|
| **概要** | 全体進捗・直近試験までの日数・平均正答率・要注意分野を一目で確認 |
| **学習進捗** | 各章を「視聴 → 理解 → 復習」の3段階でチェック。科目別・全体の進捗率を可視化。試験日もここで設定 |
| **演習スコア** | MC/TBS の正答数を記録。科目別平均正答率と正答率の推移をグラフ化。要注意分野を自動抽出 |
| **カリキュラム** | 5科目・全57章の章立てと主要トピックを俯瞰できる参照ビュー |

## 特徴

- **自動保存**: 入力はすべてブラウザの `localStorage` に保存され、次回も引き継がれます
- **外部送信なし**: データは端末内のみ。サーバ通信は一切ありません
- **ライト / ダーク対応**: ヘッダの「テーマ」ボタンで 自動 / ライト / ダーク を切替
- **カラーアクセシビリティ**: 科目カラーは検証済みパレット（色覚多様性を考慮）を採用し、常に名称ラベルを併記

## データについて

- 章立ては USCPA（アビタス）標準カリキュラム構成に基づく **学習管理用の目安** です
- 最新の出題範囲・科目構成は必ず公式教材でご確認ください
- 「リセット」ボタンで全データ（進捗・試験日・演習記録）を消去できます
