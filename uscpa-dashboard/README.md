# USCPA 対策ダッシュボード

USCPA（CPA Evolution 2024）全科目の学習を一元管理する統合対策ダッシュボードです。
Core（**FAR / AUD / REG**）＋ Discipline（**BAR・ISC** 両方収録）に対応し、
問題演習・学習進捗・学習時間・成績分析をブラウザだけで管理できます。

## 3つの使い方

1. **ブラウザで見る（ダウンロード不要）**
   Artifact URL をブラウザで開くだけ。進捗はブラウザ（localStorage）に自動保存されます。
2. **単一HTMLをダウンロードして開く**
   `index.html` を保存してブラウザで開くだけ（自己完結型・依存なし）。
3. **リポジトリから開く**
   `uscpa-dashboard/index.html` をブラウザで開く。

## 機能

| タブ | 内容 |
|------|------|
| **概要** | 学習時間の目標達成率・演習正答率・全体進捗・直近試験までの日数を一望 |
| **問題演習** | 4択MC＋TBS。科目/モード（未回答・苦手・要復習・ランダム）/種類/問題数を選び、即時採点・解説・★要復習フラグ。誤答は自動で復習対象に |
| **学習進捗** | 各章を「視聴 → 理解 → 復習」の3段階で記録。試験日（Discipline含む）も設定 |
| **学習時間** | 1500〜2000時間の目標に対する達成率、科目別内訳、直近7日集計 |
| **成績分析** | 科目別正答率・要注意トピック抽出・網羅率・演習セッション履歴 |
| **カリキュラム** | 全7科目の章立てと主要トピックの俯瞰マップ |

## ファイル構成（開発者向け）

| ファイル | 役割 |
|----------|------|
| `index.html` | **自己完結型の単一HTML**（`build.mjs` が生成。これを開けば動く）|
| `artifact.html` | claude.ai Artifact 公開用のコンテンツのみ版（`build.mjs` が生成）|
| `data.js` | 問題バンク・カリキュラムのデータ（**問題の追記はここで行う**）|
| `app.template.html` | アプリ本体のテンプレート（`data.js` を参照）|
| `build.mjs` | `data.js` を取り込み `index.html` と `artifact.html` を再生成 |

### 問題を追加してビルドし直す

1. `data.js` の `QUESTION BANK END` マーカー直前に問題を追記
2. `node build.mjs` を実行 → `index.html` と `artifact.html` が再生成される

## データについて

- データはブラウザの `localStorage` にのみ保存され、外部送信されません
- 問題・章立ては学習支援用に作成した目安です。税法の金額基準等は年度により変わるため、最新の範囲・数値は公式教材で必ずご確認ください
