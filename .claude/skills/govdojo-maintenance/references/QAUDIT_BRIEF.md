# 新しい判定演習の検算（Opus）

材料（根拠）：regs_final.json、ind_final.json、lc/lc_final.json、k_kit/kit_final.json。問題の作成規約：QUIZ_BRIEF.md。
各問の `ref` が根拠の項目を指す。

## 1問ずつ見ること
1. **正解が材料で裏づくか**（日付・対象・義務の有無・機能の挙動）。材料にない事実を使っていたら直す。
2. **錯乱肢が本当に誤りか**。半分正しい錯乱肢（正しい一般論を含むもの）、状況によっては正解にもなる錯乱肢は、はっきり誤りになるよう直す。
3. **解説 `e` が正解 `a` と噛み合っているか**（正解の番号と解説の中身の食い違いは、このリポジトリで実際に起きた欠陥）。
4. **時点と区別**：2026年10月時点で、施行済み／公布済みだが施行前／予定／提案 を取り違えていないか。ガイドラインを法的義務のように書いていないか。当てはめを規定の要求のように書いていないか。
5. **英訳**が日本語と同じ意味か。
6. 問題として成立しているか（設問だけで答えが分かる、2つ正解がある、などを直す）。
7. 「最長を選ぶ（同点は先頭）」で正解を引く形にしない（`python3 -I tools/qlen.py` で NG 0、正解が最長 10〜30%、位置 15〜35%）。

## 出力
- 入力 quiz/batch_X.json ごとに quiz/batch_X_audited.json（同じ形）と quiz/batch_X_audit.md（問番号・直した点・理由。直せない問題は削除して理由を書く）。
