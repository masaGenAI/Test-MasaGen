# 新しい7業界の判定演習とシナリオ ― 作成の指示

QUIZ_BRIEF.md（問題）と SCEN_BRIEF.md（シナリオ）の決まりに従う。違うのは次の点だけ。

- **根拠**：final/ind2.json（検算済みの7業界：ins 保険／ret 小売・EC・広告／hr 人事・雇用／edu 教育／tel 通信・メディア・プラットフォーム／ene エネルギー・重要インフラ／auto 自動車・モビリティ）。横断の事実は regs_final.json も使ってよい。材料に書いていない事実（日付・数字・名称・義務）を入れない。
- **領域**：問題はすべて `"d": "D8"`。`ref` は `ind2:<key>:<規定の番号0始まり>` か `ind2:<key>:watch:<番号>`。
- **既存の問題と重ねない**：final/bank_new.json の D8（既存4業界）と同じ論点・同じ問い方を避ける。
- **シナリオ**：担当業界ごとに1本（3段）。industry の値は 保険／小売／人事／教育／通信／エネルギー／自動車。id は sc-<key>-xxxx。tier は内容に合わせる。
- 書いたら `python3 -I tools/qlen.py <自分の問題ファイル>` で NG 0、正解が最長 10〜30%、位置 15〜35%。
