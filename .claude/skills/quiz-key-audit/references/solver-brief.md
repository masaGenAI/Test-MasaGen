# 解答役への指示（正解を伏せた問題を解く）

あなたは選択式問題の解答役です。渡されたファイルの問題を、自分の知識だけで解いてください。

## 入力

`W/in/chunk-XXXX.json`（XXXX は指示された番号）。形は次のとおりです。

```json
{ "chunk": "0001", "items": [ { "id": "0001-01", "q": "問題文", "opts": ["選択肢A", "選択肢B", "選択肢C", "選択肢D"] } ] }
```

## やること

- 各問題について、もっとも適切な選択肢を1つ選ぶ。`pick` は選択肢の番号（先頭が 0）。
- **リポジトリの原稿（`nova-app/` 以下）・`W/key.json`・`W/scan/` は開かない**。正解や解説が入っているので、見ると検品になりません。
- Web 検索はしない（自分の知識で解く。分からないときは、いちばんありそうなものを選んで `conf` を `low` にする）。
- 選択肢の長さや並びから当てにいかない。内容で選ぶ。
- 次のどれかに当たるときは、選んだうえで `issue` に短く書く：正解が2つある／正解が無い／問題文が曖昧で決められない／
  事実が古い（製品名・料金・制度が変わっている）／日本語がおかしくて意味が取れない。

## 出力

`W/out/chunk-XXXX.json` に、次の形で**全問**を書く（順番は入力と同じ）。ほかのファイルは作らない・書き換えない。

```json
{ "chunk": "0001", "answers": [ { "id": "0001-01", "pick": 2, "conf": "high", "issue": "" } ] }
```

- `conf` は `high`（確信がある）／`mid`（たぶん）／`low`（当て推量）の3つだけ。
- 書いたら、`python3 -c "import json;d=json.load(open('W/out/chunk-XXXX.json'));print(len(d['answers']))"` で件数が入力と同じことを確かめる。

## 報告

最後に、解いた件数と、`conf` ごとの件数、`issue` を書いた件数だけを1〜2行で報告してください（答えそのものは報告に書かない）。
