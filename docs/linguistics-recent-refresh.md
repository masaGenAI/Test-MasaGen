# Linguistics Hub「最近の動き」の見直し手順

`nova-app/src/ProjectNova.jsx` の `FIELD_RECENT` は、43分野に計74件（2026-10 時点：2023年11件・2024年28件・2025年28件・2026年7件）の
研究・出来事を、出典リンクつきで載せている。分野の解説（`FIELD_OVERVIEW`）と違って古くなるので、**年1回（目安は10月）**見直す。

## 1件の形

```json
{"y": "2025", "kind": "研究", "t": "見出し", "tEn": "Heading", "d": "本文（2〜3文）", "dEn": "Body", "src": [{"title": "…", "url": "https://…"}]}
```

`kind` は「研究」「出来事」「資料」のいずれか。キーは `"カテゴリ:分野"`（知識表現の細目は `"カテゴリ:分野:細目"`）。

## 手順

1. **古い項目を洗い出す**：`y` が3年以上前のものは、同じ分野で新しい動きがないかを検索し、あれば差し替える。
   差し替える場合も、分野の要点として残す価値がある古典的な結果なら `FIELD_OVERVIEW` の concepts に移すことを検討する。
2. **新しい項目を探す**：分野ごとに、主要学会（ACL・EMNLP・NAACL・COLING・Interspeech・LSA 年次大会・CogSci など）の
   その年の発表、主要コーパス・データセットの公開、標準化・政策の動きを検索する。
3. **裏取り**：出典は論文の掲載ページ（ACL Anthology、arXiv、出版社）、学会・機関の公式ページを優先する。
   この環境では出典ページを開けない（WebFetch・curl がプロキシで拒否される）ため、検索結果の題名・抜粋で
   本文に書く内容（年・著者・数値）を確かめられたものだけを書く。確かめられない数値は書かない。
4. **書き方**：本文は言い切りの短い文で2〜3文。「〜と報告した」のように、誰の主張かが分かる形にする。
   英語版（`tEn`・`dEn`）も同じ内容にする。1分野あたり1〜3件。
5. **差し込み後の確認**：
   - `cd nova-app && npm run build`（Hard errors 0）
   - Linguistics Hub の分野ページで「最近の動き」の枠に表示されること、検索（ホームの検索欄）で見出しがヒットすること
   - `python3 .claude/skills/nova-consistency-audit/scripts/stale_scan.py` で MISMATCH 0
6. この文書の先頭の件数と年の内訳を更新する。
