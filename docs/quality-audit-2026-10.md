# Project Nova 品質点検（2026-10-25）

点検の方法：データを機械的に集計したうえで、ハブごとに担当を分けてコードとデータを読んだ（読むだけ・編集なし）。数値は実測。「事実」の項目は疑いの段階で、裏取りはしていない。WebSearch で確かめた項目は根拠欄に URL がある。

影響は 高／中／低、手間は 小／中／大。
