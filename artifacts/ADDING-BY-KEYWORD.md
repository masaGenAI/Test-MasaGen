# キーワード調査で項目を追加する（Cowork 方式）

Cowork の「keyword research」と同じく、**単語（キーワード）を入力すると LLM が調べて項目を追加**するための仕組みです。

## なぜチャット方式か

公開中の Artifact はサンドボックスで動くため、**HTML 単体から外部の LLM API を呼べません**（CSP で通信がブロックされます）。そのため「調査は LLM（＝このチャットの Claude）が担当し、結果をリポジトリのデータに反映する」形にしています。

## 使い方

1. このチャットに **キーワードを送る**（1語でも複数でもOK）。例：
   - `メモ追加: RAG, MCP, ベクトルDB`
   - `学習追加: AZ-104, LangChain`
2. Claude が **Web 検索で調べ**、対象トラッカーに合わせて項目を生成します。
   - **Anything Memo**：トピック名／要約メモ（1〜2文）／ジャンル（5種から自動分類）／日付
   - **Learning**：区分（資格/Tools/講座/書籍/Udemy）／提供／名称／分類
3. `data.json` に追記 → HTML を再生成 → コミット＆Artifact を更新します。
4. 追加結果（何をどのジャンルで入れたか）をチャットで報告します。

## 対象トラッカー

| トラッカー | キーワードから生成する内容 |
|---|---|
| 🗂️ Anything Memo | トピック＋要約メモ＋ジャンル（AI/生成AI・クラウド/インフラ・開発/DevOps・ビジネス/マーケ・データ/分析） |
| 📘 Learning | 資格/講座/書籍などの名称＋提供元＋分類 |
| 📋 Daily Task | タスク名（調査というより日次項目の追加向け） |

## 補足

- ブラウザ上の **「＋追加」フォーム**は手入力用として引き続き使えます。キーワード調査は本チャット経由です。
- 重複（同じトピック／同じ区分＋名称）は自動でスキップします。
- 事実関係は Web 検索に基づきますが、最終確認は各自でお願いします。
