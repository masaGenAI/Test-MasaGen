# Learning Tracker（学習ロードマップ トラッカー・移設版）

Cowork で作成したアーティファクト **「Learning Tracker」** を、このリポジトリに移設した単体版です。

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | 単体で動く静的アプリ（タブ・サマリー・絞り込み・検索つきの一覧）。ブラウザで開くだけで動作します。 |
| `data.json` | PDFから抽出した学習項目 **全564件** ＋進捗集計（資産として保存）。 |

## 使い方

`index.html` をブラウザで開くだけです（サーバー不要・`file://` で動作）。

- タブ（全一覧 / 資格 / Tools / 講座 / 書籍 / Udemy）でカテゴリ切り替え
- 「提供」「分類」プルダウンと検索ボックスで絞り込み
- 上部にドーナツで進捗（13% 完了率）とカテゴリ別比率を表示

## 編集機能

- **＋ 項目追加** — 区分・提供・名称・分類を入力して追加（Noは区分ごとに自動採番）
- 各行の **✎ 編集 / ✕ 削除**
- 変更は **localStorage** に自動保存。**⬇ JSONエクスポート / ⬆ JSONインポート**でデータを書き出し・読み込み
- **↺ 初期データに戻す** で移設時点の564件へリセット
- カテゴリ別比率のドーナツは編集後の実件数に追従します

## 元アプリからの変更点（重要）

移設元は PDF の**見た目のスナップショット**です。以下は**無効化／制限**しています。

- ❌ **Notion即保存・セル編集**（元は編集で即Notion保存）→ 単体版はローカル保存
- ⚠️ **個別の完了ステータスはPDFから復元できない**ため、進捗ドーナツは取り込み時点の集計値（全体 71/564、資格 10/66、Tools 2/64、講座 2/53、書籍 14/261、Udemy 43/120）を表示します。行単位の「完了/未完了」は持っていません。
- ⚠️ **長い名称はPDF側で末尾が「…」に省略**されている場合があります（元の全文はPDFに含まれていません）。
