# Anything Memo Tracker（移設版）

Cowork で作成したアーティファクト **「Anything Memo Tracker」** を、このリポジトリに移設した単体版です。

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | 単体で動く静的アプリ。ブラウザで開くだけで動作します。 |
| `data.json` | PDFから抽出したメモ18件・ジャンル5種のデータ（資産として保存）。 |

## 使い方

`index.html` をブラウザで開くだけです（サーバー不要・`file://` で動作）。

- 上部の検索ボックスでトピック・メモ・ジャンルを横断検索
- ジャンルチップで絞り込み、「並び替え：日付順」で昇順/降順を切り替え

## キーワードから調べて追加（Chrome内蔵AI）

- 上部の「🔎 キーワードから調べて追加」に単語を入れて **調べて追加** を押すと、**Chrome内蔵AI（Gemini Nano / Prompt API）** が端末内で要約文とジャンルを生成し、そのまま1件追加します。
- **APIキー不要・ネット送信なし**（オンデバイス）。ただし **Web検索はしない**ため内容は要確認、生成結果はカードの ✎ で修正できます。
- **要件**: 対応ブラウザ（Chrome。内蔵AIモデルが利用可能なこと。初回はモデルDLあり）。**公開中のArtifactはサンドボックス制約で動かない**場合があります → その場合は下記の手入力フォームに自動で切り替わり、調査プロンプトをクリップボードにコピーします（このチャットや他のLLMに貼って使えます）。
- 高精度に「調べて」ほしい場合は、引き続き**このチャットにキーワードを送る運用**（Web検索で裏取り）が確実です。

## 編集機能

- **＋ メモ追加** — トピック・ジャンル・日付・メモを入力して追加
- 各カードの **✎ 編集 / ✕ 削除**
- 変更は **localStorage** に自動保存（このブラウザに保持）
- **⬇ JSONエクスポート / ⬆ JSONインポート** でデータを書き出し・読み込み（リポジトリの `data.json` に反映したい場合はエクスポートしたJSONを取り込めます）
- **↺ 初期データに戻す** で移設時点の18件へリセット

## 元アプリからの変更点

移設元は PDF の**見た目のスナップショット**です。以下は**無効化**しています。

- ❌ **Notion連携**
- ❌ **トピッククリックでの詳細サブページ遷移**（編集はカードの ✎ ボタンから）
